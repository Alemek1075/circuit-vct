# Дизайн Circuit

## Аудиторія й завдання

Глядач Champions хоче за кілька секунд побачити результат, знайти команду і простежити її шлях. Сторінка нагадує операторський аркуш трансляції: числа, короткі позначення й траєкторії матчів мають більшу вагу за рекламу або декоративний hero.

## Токени

| Роль | Значення |
| --- | --- |
| Полотно | `#101c23` нічний синьо-зелений |
| Панель | `#172832` темніша дошка результатів |
| Лінія | `#34505a` для зв'язків і роздільників |
| Текст | `#f2f0e9` теплий білий |
| Вторинний текст | `#9aafb5` |
| Акцент результату | `#e8a24b` теплий бурштин |
| Акцент майбутньої гри | `#76b8ba` холодний бірюзовий |
| Негативний/вибування | `#d97870` |

Шрифт заголовків: **Barlow Condensed**, важкий, компактний як трансляційний титр. Основний текст: **IBM Plex Sans**. Час, рахунок, ID матчу й числові таблиці: **IBM Plex Mono**. Шрифти зберігати локально. Ритм 4/8/12/20/32/48 px. Радіус 2–4 px лише для кнопок і матчів; без скляних ефектів, градієнтів та декоративних карток.

## Структура

Широкий екран: вузька ліва навігація, зверху компактний контекст турніру, далі головна сітка. Над сіткою один короткий результат фіналу, який дійсно підсумовує архів. Під сіткою таблиця місць і матчі. Матчі у стовпцях, між ними геометричні лінії переходу. Нижня сітка окремою смугою, щоб рух після поразки був читабельним.

Мобільний екран: верхня панель замість бічної; стовпці сітки прокручуються в її межах із помітною підказкою. Таблиця скорочується до найважливіших полів. Деталі матчу відкриваються в окремій доступній панелі без втрати контексту.

Запам'ятовуваний елемент: **маршрут команди**. При виборі команди підсвічуються її картки й з'єднання в сітці, інші стихають. Це допомагає читати складну сітку, а не просто прикрашає її.

## Доступність і рух

Контраст щонайменше WCAG AA для звичайного тексту. Видимий `:focus-visible`, мінімальна активна площа 44 px, семантичні кнопки, таблиці та назви раундів. Анімація лише для зміни виділення, максимум 160 ms, вимикається через `prefers-reduced-motion`.
