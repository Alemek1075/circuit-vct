# Circuit: турнірні сітки VALORANT

## Мета

Неофіційний українськомовний сайт для читання результатів Champions Paris 2025 і календаря Champions Shanghai 2026. Головна дія відвідувача: простежити шлях команди крізь верхню й нижню сітки, відкрити конкретний матч і зрозуміти, звідки прийшли суперники. Архівні рахунки відокремлені від майбутніх матчів; сайт не видає себе за офіційне джерело або live feed.

## Дані та джерела

- Результати плейоф Champions Paris 2025, учасники й місця: [VLR.gg](https://www.vlr.gg/event/2283/). Чемпіон і фінальний рахунок також підтверджені [NRG](https://nrg.gg/blogs/news/valorant-world-champions).
- Формат Champions Shanghai 2026, 16 учасників, групи GSL, плейоф із двома шансами на виліт: [офіційний довідник VALORANT Esports](https://valorantesports.com/en-US/tournament/115576361459045501/overview).
- Пари перших матчів Shanghai 2026: [офіційний розклад](https://valorantesports.com/en-US). Зафіксований знімок даних від 24.09.2026; автоматичного оновлення офіційних результатів немає.

## Модель

- `Tournament`: назва, сезон, місто, дати, стан, джерело.
- `Team`: назва, скорочення, регіон, колір, посилання на зображення/логотип за наявності, участь у турнірі.
- `Match`: турнір, стадія, раунд, позиція, дві команди або очікувані слоти, рахунок, формат BO3/BO5, дата, переходи переможця та команди, що програла.

Усі рахунки мають бути реальними й перевіреними або залишатися порожніми. Порожнє значення показується як майбутня гра, а не 0:0.

## Обсяг

1. Адаптивна публічна сторінка: вибір турніру, таблиця результатів/посіву, верхня й нижня сітки з видимими зв'язками, розклад, деталі матчу й команди, пошук.
2. MVC CRUD для трьох сутностей на SQLite та JSON CRUD API з пагінацією матчів. Введення перевіряється; небезпечні посилання відхиляються.
3. Наскрізні й API тести, Docker Compose, CI. Секрети й локальна БД не потрапляють у Git.
4. Публічний статичний експорт без операцій запису можна розгортати автоматично. Публікація динамічного сервера потребує OAuth2, постійної бази та перевірки хмари.

## Приймання

- Читач бачить достовірну завершену сітку Paris 2025 з верхнім і нижнім шляхом та може відкрити кожний із 14 матчів.
- Shanghai 2026 показує 16 учасників і перші вісім оголошених матчів без вигаданих рахунків; дати/стани чітко підписані.
- Пошук команди підсвічує її матчі; фільтри й вибір турніру доступні з клавіатури.
- Мобільна версія не має горизонтального переповнення всієї сторінки; сітка має керований горизонтальний перегляд, якщо це потрібно.
- CRUD, API та перевірки виконуються з чистого клонування за README.

## Межі

Circuit є навчальним фанатським проєктом, не пов'язаним із Riot Games або VCT. Назви команд використані як факти про турнір; офіційні логотипи й матеріали гри не копіюються. Архівний знімок не називається живими даними.
